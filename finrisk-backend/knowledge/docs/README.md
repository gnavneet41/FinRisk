# Knowledge documents

Put reference notes here as `.md` or `.txt` files (for example summaries of textbook chapters, accounting standards or regulator guidance you are allowed to use).

- Files are split into chunks at headings and blank lines.
- Chunks are indexed when the server starts (restart after adding files).
- The Risk Advisor and the chatbot retrieve the most relevant chunks and cite them by id, e.g. `DOC-ratio_definitions-3`.
- This README is not indexed.

Do not add made-up benchmarks. If you add a benchmark, include its source.
